# **Library Link**
The application is a book lending web application called Library Link where users can digitally manage books which they own. <br/>
They will be able to lend books to others and track the status of their books. The core features of the application will consist <br/>
of a Book catalog management, lending process, book search and filter, and Lending history tracking. The book catalog management <br/>
will allow users to add, edit, view, and delete book entries. The lending process will enable users to mark when a book is lent <br/>
out and specify the borrower by name/email, as well as setting an expected return date. The book search and filter feature will <br/>
allow users to browse and search for books using their title/author, and filter by availability. Finally, the lending history tracking <br/>
will keep a record of all borrowed books, including who borrowed each book and when they would be returned.<br/>
